AED for USB - 사용법 (Windows)
=================================

1) USB 를 PC 에 꽂는다.
2) aed.exe 를 더블클릭한다. (UAC 가 뜨면 "예"를 눌러 관리자 권한 허용)
3) 마법사 화면이 안내하는 순서대로 진행:

   [1/5] 장치 스캔 + 건강 진단
         - 모든 디스크가 표시되고, 의심 USB 는 [BAD]/[WARN] 로 표시됨

   [2/5] 복구할 USB 선택 (번호 입력)

   [3/5] 이미지 파일 경로 지정 (기본값 사용 권장)
         - 원본 USB 는 절대 쓰지 않음. 이미지로 안전 복제만 함
         - 배드 섹터는 자동 재시도 + 스킵, 진행상황은 .aedlog 에 저장
         - 중간에 멈춰도 다시 실행하면 이어받기

   [4/5] 복구 전략 선택
         1) Filesystem walk  - FAT12/16/32 살아있는 파일 복구 (가장 정확)
         2) Mount + copy     - NTFS / exFAT (Windows 가 파일시스템을 읽을 수 있을 때)
         3) Signature carve  - 파일시스템이 깨졌을 때 헤더로 추출
                               (JPEG, PNG, PDF, MP4, Office, HWP, ZIP, ...)

   [4/5] 복구 범위 선택
         - 전체 / 특정 폴더 / 패턴(*.jpg) / 삭제된 파일 포함

   [4/5] 복구 결과를 받을 폴더 지정

   [5/5] 진행률 / 속도 / ETA 가 실시간 표시됨


CLI 모드 (마우스 없이)
=================================
관리자 권한 cmd 에서:

   aed.exe scan
   aed.exe health
   aed.exe image \\.\PhysicalDrive2 D:\usb.img
   aed.exe analyze D:\usb.img
   aed.exe recover D:\usb.img D:\out --include-deleted
   aed.exe carve   D:\usb.img D:\out


중요 안전 수칙
=================================
- 복구할 USB 에 절대 쓰기 작업을 하지 마세요. 포맷도 안 됩니다.
- 이미지 (.img) 는 USB 와 같은 크기입니다. 충분한 여유 공간이 있는
  드라이브 (HDD/SSD) 에 저장하세요.
- 파일 탐색기에서 USB 가 안 열려도 (RAW 표시) 디스크 관리(diskmgmt.msc)
  에서 보이기만 하면 이 도구로 복구 가능합니다.
